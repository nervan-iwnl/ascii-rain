# Пока идёт дождь

[Открыть сайт](https://nervan-iwnl.github.io/ascii-rain/)

Маленький ASCII-лес с дождём и интернет-радио.

## Файлы

- `index-readable.html` — читаемый исходник. Все правки делайте здесь.
- `index.html` — компактная версия для GitHub Pages. Создаётся скриптом.
- `build.cjs` — минификация HTML, CSS и JavaScript.
- `.nojekyll` — отключает обработку страницы Jekyll.

## Как обновить сайт

Один раз установите инструменты сборки:

```sh
npm install
```

После изменения `index-readable.html`:

```sh
npm run build
git add index-readable.html index.html
git commit -m "Update site"
git push
```

Скрипт показывает размер HTML и gzip. GitHub Pages публикует `index.html` из корня ветки `main`. Сборочная библиотека не загружается посетителями.

## Клавиши

- Пробел — общая пауза музыки, шума дождя и анимации.
- M — включить/выключить музыку, включая русскую раскладку.
- 0 / 1 / 2 — выключить дождь, тихий дождь, ливень.
- ↑ / ↓ — громкость музыки с шагом 5%.
- Shift + ↑ / ↓ — громкость дождя.

В ползунках и выборе станции клавиши управляют самим элементом.

## Загрузка

Стили и код встроены в HTML. Для страницы нужен один HTTP-запрос; аудиопоток подключается отдельно после нажатия. Надпись «никуда не нужно спешить» появляется каждые 50 секунд.

Один запрос не означает один TCP-handshake или гарантированную передачу в первом окне TCP. Настройки соединения определяет GitHub Pages.
