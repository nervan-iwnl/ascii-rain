# Пока идёт дождь

[Открыть сайт](https://nervan-iwnl.github.io/ascii-rain/)

ASCII-лес, дождь и интернет-радио. Страница полностью находится в `index.html`: стили и JavaScript встроены, внешние ресурсы при открытии не нужны. Радио подключается только после нажатия воспроизведения. GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll.

## Клавиши

- Пробел — общая пауза.
- M — музыка (работает и при русской раскладке).
- 0 / 1 / 2 — сила дождя.
- ↑ / ↓ — громкость музыки.
- Shift + ↑ / ↓ — громкость дождя.

Когда фокус находится в ползунке или выборе станции, клавиши управляют этим элементом.

## Изменение сайта

Редактируйте `src/index.html`, затем выполните `npm install` и `npm run build`. Сборка обновляет готовый `index.html`. После коммита и `git push` Pages публикует изменения. Библиотека сборки не загружается браузером посетителя.

## Загрузка

Размер HTML — 11 989 байт. Одна загрузка HTML содержит весь интерфейс. Это не обещание передачи за один TCP-handshake: TCP и TLS требуют установки соединения, а начальное окно передачи задаётся хостингом и сетью. GitHub Pages не позволяет настраивать его. Для проверки используйте URL со слешем в конце, чтобы избежать перенаправления.
